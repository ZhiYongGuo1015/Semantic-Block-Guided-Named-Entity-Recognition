# Code Overview

## Core Training Code

`src/geo_semantic_bert_suite.py` is the main experiment entry point. It supports:

- BERT-FC and RoBERTa-FC baselines;
- BERT/RoBERTa with CRF decoding;
- RoBERTa-BiLSTM-CRF;
- RoBERTa-BiGRU-CRF;
- RoBERTa-BiGRU-Attention-CRF;
- semantic block feature injection;
- residual semantic block gate;
- semantic block adapter;
- type emission gate;
- block-adaptive CRF;
- R-Drop regularization;
- semantic perturbation evaluation;
- prediction export for dev/test sets.

`src/public_ner_bert_suite.py` provides shared utilities:

- BIO file reading;
- tag vocabulary construction;
- span extraction from BIO tags;
- entity-level precision, recall, and F1 calculation;
- tokenizer and dataloader preparation;
- baseline PLM sequence tagging model.

`src/public_ner_classic_suite.py` contains classical NER utilities used for supplementary baseline experiments.

`src/build_auto_k_semantic_splits.py` is an exploratory script for automatic K-class semantic block construction. It is not the main manuscript route, but is retained because it documents one explored alternative.

## Reproducibility Scripts

| Script | Purpose |
|---|---|
| `scripts/run_seed42_main.sh` | Runs the paper's seed=42 comparison among RoBERTa-CRF variants and RoBERTa-SBG-CRF. |
| `scripts/run_multiseed_main7.sh` | Runs 5 seeds for BERT-FC, RoBERTa-FC, RoBERTa-CRF variants, and RoBERTa-SBG-CRF. |
| `scripts/run_report_level_main5.sh` | Runs report-level split evaluation. |
| `scripts/run_backbone_specific_semantic.sh` | Runs targeted semantic-block adaptations for BiLSTM, BiGRU, and BiGRU-Attention backbones. |

## Summarization Scripts

The scripts under `scripts/summarize/` read `semantic_bert_results.json` files generated by the training code and produce Markdown summary tables.

They assume the same directory names as the provided run scripts.
